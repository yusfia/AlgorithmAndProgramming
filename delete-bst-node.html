Teori Lengkap Deletions BST

Operasi penghapusan (*Deletion*) pada Binary Search Tree (BST) memiliki aturan yang ketat untuk menjaga sifat fundamental dari BST: Nilai di sub-tree kiri selalu lebih kecil dari node induk, dan nilai di sub-tree kanan selalu lebih besar.

Kasus 1 Node Tanpa Anak (Leaf Node)

Node target tidak memiliki anak sama sekali (terletak di paling ujung bawah). Penghapusan dilakukan dengan langsung memutus link dari parent node menuju node ini dan menyetel referensinya ke NULL.

Kasus 2 Node Memiliki 1 Anak

Node target hanya memiliki sub-tree kiri atau kanan saja. Kita menghapus node tersebut dan melompati posisinya dengan cara menghubungkan satu-satunya anaknya langsung ke parent dari node yang dihapus (menghubungkan anak langsung ke kakeknya).

Kasus 3 Node Memiliki 2 Anak

Ini kasus paling kompleks. Kita tidak bisa langsung memutus jalur karena akan merusak struktur di bawahnya. Solusi:

  1. Cari pengganti ideal: In-order Successor (nilai terkecil di sub-tree kanan).
  2. Salin nilai successor tersebut ke node target.
  3. Hapus node successor asli di bagian sub-tree kanan (yang pasti masuk kategori Kasus 1 atau Kasus 2).

🎮 Menggunakan Skenario Kasus

Tekan tombol salah satu kasus (Kasus 1, Kasus 2, atau Kasus 3) di bagian atas untuk langsung menyusun pohon contoh yang ideal untuk kasus tersebut. Target node otomatis disiapkan di form simulasi.

▶️ Pemutaran Simulasi (Playback)

Setelah menekan Simulasi Hapus, panel kontrol simulasi akan muncul di atas pohon. Anda bisa menekan tombol Play untuk menonton otomatisasi jalannya algoritma, atau melangkah manual satu-persatu dengan menekan tombol panah Chevron (Kiri/Kanan).

🪵 Bangun Pohon Sendiri (Playground)

Ingin menguji pohon buatan Anda sendiri? Masukkan nilai apa saja pada input numerik di atas, lalu tekan Sisipkan untuk menambahkan node baru ke BST. Anda juga dapat melakukan Hapus Instan jika tidak ingin melewati langkah-demi-langkah simulasi.
