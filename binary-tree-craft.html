Modul Pembelajaran

Memahami Jenis-Jenis Binary Tree

Binary Tree (Pohon Biner) adalah struktur data hierarkis di mana setiap elemen (disebut node) memiliki paling banyak dua anak, yang biasa disebut sebagai **anak kiri (left child)** dan **anak kanan (right child)**. Berdasarkan bentuk struktur dan penempatan nodenya, binary tree diklasifikasikan menjadi beberapa jenis penting berikut ini.

1. Full Binary Tree

Strictly

Sebuah pohon biner di mana setiap node memiliki tepat 0 atau 2 anak. Tidak boleh ada satu pun node di dalam pohon ini yang hanya memiliki anak tunggal.

Ciri Utama:

Node anak ≠ 1. Jika ada cabang, wajib bercabang dua.

2. Complete Binary Tree

Rata Kiri

Semua tingkatan (level) terisi penuh kecuali mungkin tingkat terakhir. Khusus pada tingkat terakhir, semua node wajib terisi rapat dari sisi kiri ke kanan tanpa ada celah kosong.

Ciri Utama:

Pengisian bertahap & adil dari kiri. Sangat krusial untuk struktur data Binary Heap.

3. Perfect Binary Tree

Sempurna

Kasus ideal di mana semua internal node memiliki tepat 2 anak, dan semua leaf node (ujung daun) berada pada level kedalaman yang sama.

Rumus Kapasitas:

Jumlah node n = $2^{h} - 1$
(h = tinggi pohon)

4. Balanced Binary Tree

Seimbang

Sebuah pohon biner di mana selisih tinggi (kedalaman) antara sub-pohon kiri dan sub-pohon kanan untuk setiap node tidak pernah lebih dari 1.

Ciri Utama:

Menjamin efisiensi waktu pencarian konstan $O(\log n)$ (contoh: AVL Tree, Red-Black Tree).

5. Degenerate (Pathological)

Linear

Kondisi terburuk di mana setiap internal node hanya memiliki satu anak. Akibatnya, struktur pohon memanjang linear ke bawah.

Dampak Buruk:

Kehilangan fungsi efisiensi pohon; kecepatan pencarian menurun drastis menjadi linear $O(n)$ layaknya Linked List.

Hubungan Logika

Berikut ringkasan hubungan hierarkis antar-pohon yang perlu Anda ingat:

  • Setiap Perfect Tree sudah pasti merupakan Complete dan Full Tree.
  • Sebuah Complete Tree belum tentu merupakan Full Tree (misal node genap yang punya anak tunggal di level bawah).
  • Sebuah Full Tree belum tentu seimbang (Balanced).
Mode Tantangan Level 1/5

Buat Pohon Full

Penyihir struktur data menginginkan sebuah **Full Binary Tree** dengan tepat **5 node**. Ingat, pada Full Tree setiap node harus memiliki tepat 0 atau 2 anak!

💡 Tips Aturan:

  • Full: Semua node punya anak 0 atau 2.
  • Complete: Padat di atas, bawahnya rata kiri.
  • Perfect: Semua level penuh sempurna.
  • Balanced: Selisih tinggi kiri & kanan maks 1.
